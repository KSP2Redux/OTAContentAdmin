# Security policy

Redux OTA Admin can publish content consumed by KSP2 Redux clients. Please do not disclose authentication, authorization, secret-handling, upload, or publication vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting for this repository. Include the affected version or commit, reproduction steps, impact, and any suggested remediation. Do not test against the production service or production integrations without explicit authorization.

Public issues are appropriate for non-sensitive defects and feature requests.
